# קוראים בכיף 🦉

אפליקציית רשת (PWA) לתרגול קריאה וכתיבה בעברית לילדים בכיתות ג–ו.
עובדת בדפדפן, ואפשר להתקין אותה על מסך הבית של הטלפון כמו אפליקציה רגילה.
אחרי הכניסה הראשונה היא עובדת גם בלי אינטרנט.

המחקר שעליו היא מבוססת נמצא ב-[RESEARCH.md](RESEARCH.md).

## מה יש בפנים

**📖 קריאה** — כל טקסט עובר 6 שלבים:
1. **מילים חשובות** — היכרות מוקדמת עם 3–4 מילים קשות מהטקסט.
2. **מקשיבים** — ינשופי מקריא, והמילה שנקראת מודגשת בצהוב.
3. **קוראים כמו הד** — ינשופי קורא משפט, והילד/ה חוזר/ת עליו.
4. **קוראים לבד** — קריאה בקול, עם הקלטה. אין שעון גלוי. נגיעה במילה משמיעה אותה, ויש סרגל קריאה.
5. **מבינים** — שאלות הבנה. כשטועים, המשפט עם התשובה נצבע בירוק.
6. **כותבים** — תגובה קצרה לטקסט, בעזרת פתיחי משפטים ומחסן מילים.

**🎮 משחקי מילים**
- **אותיות חברות** — ט/ת, כ/ח, ק/כ, א/ע, ס/שׂ, ב/ו, עם רמז ומשפחת מילים.
- **עץ השורשים** — מסדרים מילים לפי השורש שלהן.
- **בונים משפט** — מסדרים מילים למשפט.
- **מחברים משפטים** — בוחרים מילת קישור: כי, אבל, ולכן.
- **מסתכלים וכותבים** — מילים שהיו קשות לילד/ה חוזרות לתרגול.

**✏️ כתיבה**
- בונים סיפור לפי מפת סיפור: מי ← איפה ← בעיה ← פתרון ← סוף.
- ינשופי מקריא בקול את הסיפור שהילד/ה כתב/ה.
- המשוב מתחיל בחוזקות, ואחריו טיפ אחד בלבד.

**🏆 תגמול**
- מקבלים כוכבים על מאמץ, ויש מדבקות לאסוף.
- יש מטרה שבועית (למשל 4 ימים בשבוע) ולא "רצף" שנשבר.

**👨‍👩‍👧 אזור הורים** (נכנסים בפתרון תרגיל כפל):
- התקדמות: דקות תרגול, מילים לדקה (להורה בלבד), הצלחה במשחקים, מילון אישי.
- האזנה להקלטות של הילד/ה.
- קריאת כל מה שהילד/ה כתב/ה.
- **הוספת טקסטים** מהשיעור או מספר הלימוד.
- **הקלטה של ההורה** קורא כל משפט, כך שהילד/ה ישמע/תשמע את הקול שלכם במקום קול ממוחשב.
- הגדרות קול, גיבוי ושחזור.

## משתמשים וכניסה

- כל ילד/ה נכנס/ת עם שם משתמש וסיסמה. אפשר להירשם לבד ממסך הכניסה, והמנהל יכול לסגור את ההרשמה.
- ההתקדמות נשמרת בשרת, כך שאפשר להמשיך מכל מכשיר. ההקלטות נשמרות רק במכשיר שבו הוקלטו.
- **מנהל:** בכניסה הראשונה משתמשים בשם `admin` ובסיסמה `admin`, ואז חייבים לבחור סיסמה חדשה.
- במסך **🛡️ ניהול** אפשר לראות את כל המשתמשים ואת ההתקדמות של כל אחד. אפשר גם להוסיף משתמש, לאפס סיסמה, לחסום, למחוק, או להפוך משתמש למנהל.
- השרת בנוי על Cloudflare Pages Functions (`functions/api`) עם מסד נתונים D1 (`kria-db`). הסיסמאות נשמרות מוצפנות (PBKDF2).

## הפעלה במחשב

```bash
npm install
```

```bash
npm run dev
```

ואז לפתוח את http://localhost:8765. בהרצה מקומית יש מסד נתונים מקומי, נפרד מהאתר החי.

## העלאה לאתר

```bash
npm run deploy
```

## התקנה על הטלפון

כדי שהאפליקציה תעבוד על הטלפון ושהמיקרופון יעבוד, היא צריכה כתובת https. הדרך הפשוטה:

1. להיכנס ל-https://app.netlify.com/drop (צריך להירשם, זה חינם).
2. לגרור לשם את התיקייה `app`.
3. לפתוח בטלפון את הכתובת שמתקבלת:
   - **iPhone:** בספארי, כפתור שיתוף ← "הוסף למסך הבית".
   - **Android:** בכרום, תפריט ⋮ ← "התקן אפליקציה".

אפשרויות נוספות: GitHub Pages או Cloudflare Pages.

## חשוב לדעת

- **כל הנתונים נשמרים רק במכשיר.** זה כולל התקדמות, הקלטות וכתיבה, ושום דבר לא נשלח לשום מקום. בטלפון אחר מתחילים מאפס. אפשר להעביר נתונים בעזרת "גיבוי" באזור ההורים (הגיבוי לא כולל את ההקלטות).
- **הקול הממוחשב** הוא הקול העברי של המכשיר:
  - ב-iPhone ובמק: Carmit.
  - באנדרואיד: Google, ולפעמים צריך להוריד קול עברי בהגדרות המכשיר.
  - ב-Windows: עדיף דפדפן Edge.
- **באייפון**, כשהאפליקציה מותקנת על מסך הבית, המיקרופון עלול לא לעבוד. אם זה קורה, אפשר לפתוח אותה בספארי.
- **הניקוד בטקסטים** נכתב בקפידה, אבל כדאי שמבוגר יעבור עליו. רשימת מילים לבדיקה נמצאת ב-RESEARCH.md.
